# Pokemon 3D Starters

Cena 3D interativa com os 3 pokemons iniciais clássicos — Bulbasaur, Charmander e Squirtle — iluminação studio Three.js.

## Stack

- HTML5 semântico
- CSS3 custom properties
- Three.js
- WebGL

## Estrutura

```

js/script.js
assets/
index.html
```
