# ALPHABET Store — Stationery E-commerce

Landing page de e-commerce de papelaria e itens de escritório. Produtos: washi tape, cadernos, acessórios e mesas divertidas.

## Stack

- HTML5 + Tailwind CSS v4 (CDN)
- Swiper.js
- Lucide Icons
- JavaScript puro

## Seções

1. **Hero** — "Fun & Styled Desk"
2. **New Arrivals** — Novos produtos em destaque
3. **Carousel** — Swiper com categorias (desk accessories, pens, notebooks)
4. **Newsletter** — Captura de email
5. **Footer** — Contato e redes sociais
