# Modelo — Boilerplate

Template base para novos projetos do showcase. Estrutura mínima com HTML5, CSS e JavaScript.

## Stack

- HTML5 semântico
- CSS3 com custom properties
- JavaScript puro

## Estrutura

```
css/style.css   — estilos do projeto
js/script.js    — lógica do projeto
index.html      — entry point
```
