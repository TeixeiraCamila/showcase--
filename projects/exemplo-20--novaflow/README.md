# NovaFlow — Intelligence-Driven Logistics & Risk Management

Landing page para plataforma enterprise de logística com IA. Combina prevenção de riscos, monitoramento de cargas em tempo real e soluções integradas.

## Stack

- HTML5 + Tailwind CSS v4 (CDN)
- Swiper.js
- AOS (Animate on Scroll)
- GSAP
- Lucide Icons

## Seções

1. **Hero** — "Logistics Designed For The Speed Of Modern Business"
2. **Platform** — Visão geral da plataforma
3. **Services** — Serviços de logística
4. **Industries** — Indústrias atendidas
5. **Tech** — Diferenciais tecnológicos
6. **Testimonials** — Depoimentos
7. **Footer** — Contato e links
