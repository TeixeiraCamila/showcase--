# Notely — Your Story, Your Notebook

E-commerce landing page for personalized notebooks. Built with Tailwind CSS v4 and GSAP animations.

## Stack

- HTML5 + Tailwind CSS v4 (CDN)
- GSAP 3.13.0 (ScrollTrigger, SplitText)
- Lucide Icons
- Karla (Google Fonts)

## Sections

1. **Hero** — "Your story, your notebook" with split-text logo, floating blobs, and dual CTAs
2. **Features** — 3 cards: Fully Customizable, Made with Love, Quick Delivery
3. **History** — Brand origin story with vintage notebook mockup
4. **Email CTA** — Newsletter signup form with decorative rings
5. **Story** — Navy section with abstract visual and "Start Designing" CTA
6. **Footer** — Copyright + back link

## Local Dev

```bash
python -m http.server 8000
# Open http://localhost:8000/projects/exemplo-04--notely/
```

No build step — just serve the root.
