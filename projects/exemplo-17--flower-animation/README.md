# Flower Animation

Animação floral interativa com efeitos visuais em CSS e JavaScript. Galeria de flores com animações suaves ao passar o mouse.

## Stack

- HTML5 semântico
- CSS3 custom properties + keyframes
- JavaScript puro

## Estrutura

```
css/style.css
js/script.js
assets/
index.html
```
