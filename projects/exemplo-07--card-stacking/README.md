# Card Stacking Animation

Landing page interativa com animação inovadora de empilhamento de cards usando GSAP.

## Stack

- HTML5 semântico
- CSS3 custom properties
- GSAP (Draggable, InertiaPlugin, ScrollTrigger)
- Tailwind CSS

## Estrutura

```
css/style.css
js/script.js
assets/
index.html
```
