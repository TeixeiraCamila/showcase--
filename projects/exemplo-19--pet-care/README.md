# PetCare — Premium Pet Care

Landing page completa para serviços premium de cuidados pet: wellness checkups, grooming, boarding, training e nutrition.

## Stack

- HTML5 + Tailwind CSS v4 (CDN)
- GSAP (ScrollTrigger)
- Lucide Icons
- JavaScript puro

## Seções

1. **Hero** — "Premium Pet Care for Your Furry Family"
2. **Services** — Cards de serviços oferecidos
3. **Why Us** — Diferenciais competitivos
4. **Adoption** — Seção de adoção
5. **Testimonials** — Depoimentos de clientes
6. **Blog/Newsletter** — Blog e captura de leads
7. **Footer** — Contato e redes sociais
