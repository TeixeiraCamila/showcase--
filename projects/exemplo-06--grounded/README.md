# Blue Tone Retreats — Breathwork

Landing page para retiros e práticas imersivas de breathwork. Hero com parallax, seções animadas com GSAP, depoimentos e formulário de contato de demonstração (mockup).

## Stack

- HTML5 semântico + ARIA labels
- Tailwind CSS (CDN) + CSS3 custom properties
- GSAP (ScrollTrigger, ScrollToPlugin)
- Lucide Icons
- Google Fonts (Atkinson Hyperlegible, Cormorant Garamond)

## Estrutura

```
css/reset.css
css/style.css
js/script.js
index.html
```
