# Catpuccino — Coffee, Cats & Comfort

Landing page de cafeteria com temática retrô-moderna voltada para Gen Z Creators. Inclui light & dark mode.

## Stack

- HTML5 semântico + ARIA
- CSS3 com custom properties
- JavaScript puro

## Seções

1. **Hero** — Logo animado + tagline "Coffee, Cats & Comfort"
2. **About** — História do café com decoração vintage
3. **Menu** — Cards de bebidas e comidas
4. **Gallery** — Grid de fotos estilo Polaroid
5. **Footer** — Redes sociais + localização
